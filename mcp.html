MCP server

Surfacing Feelings for your AI assistant

A free MCP server that gives Claude, ChatGPT, and other AI assistants the Surfacing feelings list: 796 feeling words in 22 categories and a body map of 243 physical sensations. When someone can't find the word for what they feel, the assistant can look it up instead of guessing.

https://surfacing-mcp.knightcorrick.workers.dev/mcp

Streamable HTTP. No account, no API key, no sign-in.

Add it to Claude

  1. Open Settings, then Connectors.
  2. Choose Add custom connector.
  3. Name it Surfacing Feelings, paste the URL above, and save. No authentication is needed.
  4. In a chat, try: "I feel off today and I can't name it. Help me find the word."

Add it to other assistants

  • ChatGPT: with developer mode on, add a connector with the URL above and no authentication.
  • Claude Code, Cursor, VS Code, and other MCP clients: add a remote (HTTP) MCP server with the URL above. For Claude Code: claude mcp add --transport http surfacing-feelings https://surfacing-mcp.knightcorrick.workers.dev/mcp

Tools

list_categories

Every feeling category with example words, plus every body region.

get_feeling_words

All the words in one category, such as Sadness, Overwhelmed, or Calm & Grounded.

get_body_sensations

The sensations people report in one body region, such as Heart & Chest or Stomach.

search_words

Search every feeling and sensation for a word or fragment, such as "heavy" or "tight".

All tools are read-only. The word list is the same one built into the Surfacing app and shown on the Feelings List page.

Privacy

The server stores nothing. It has no database, request logging is off, and it never sees your Surfacing entries. Your conversation stays with your AI provider. Full details are in section 8 of the privacy policy.

Not therapy or crisis support. This server provides words, not advice or diagnosis. If you are in crisis, in the US call or text 988. Elsewhere, contact local emergency services.
